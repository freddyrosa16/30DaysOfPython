# 30 Days of Python

My exercises and practice notes as I learn Python through Asabeneh Yetayeh’s **30 Days of Python** challenge.

This repository tracks my work in progress, from basic syntax to functions, collections, and text processing. It contains exercises through Day 18, with some exercises still unfinished; it is not a completed solution set.

## Topics covered

| Days | Topics |
| --- | --- |
| 1–4 | Python basics, variables, arithmetic, and strings |
| 5–8 | Lists, tuples, sets, and dictionaries |
| 9–12 | Conditionals, loops, functions, and modules |
| 13–14 | List comprehensions and higher-order functions |
| 16–18 | Dates and times, exception handling, and regular expressions |

## Run an exercise

Use Python 3 and run commands from the repository root. For example:

```sh
python3 -m day_1.helloworld
python3 -m day_18.regular_expressions
```

Use the same module pattern for other days: replace the folder and filename, leaving off `.py`. Running from the root also lets exercises import the shared `data` modules.

Some exercises print results immediately, some define functions to experiment with, and others ask for terminal input. Read the exercise comments before running a file.

## Repository structure

- `day_*/`: Exercises grouped by day and topic.
- `data/`: Country names and country records used in the exercises.

The current folders cover Days 1–14 and 16–18. New work will be added as I progress.
